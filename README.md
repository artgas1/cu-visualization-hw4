# Мои заказы — интерактивный dashboard

## Запуск

Это статический сайт без npm и сборки. Для корректной загрузки локальных `data.js` и изображений откройте папку через любой локальный сервер:

```bash
cd output/visualization-hw4
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000/`. Сервер в рамках подготовки задания не запускался.

## Данные и определения

- Источник: `data.js`, объект `window.HW_DATA`, только доставленные заказы, сентябрь 2021 — август 2026.
- Заказы: число уникальных значений `order`.
- Расходы: сумма `amount` (оплаченная сумма).
- Взвешенная скидка: `1 - sum(amount) / sum(price * quantity)`.
- Взвешенная цена покупки товара: `sum(amount) / sum(quantity)`.
- Метрики относятся к выбранному месяцу; категории и товары — к окну последних 24 месяцев.
- Товарный график исключает только категорию `Услуги Груши`; категория остаётся в общей структуре.

## Библиотеки

- Vue 3, локальный файл `vendor/vue.global.prod.js`.
- D3 7, локальный файл `vendor/d3.min.js`.

## Что покрыто

- Фильтр месяца и категории, сброс, явный выбранный месяц.
- Три KPI с отдельными D3 SVG-графиками за 24 месяца и true zero baseline.
- Две связанные шкалы горизонтальных баров: количество и расходы.
- Топ-12 товаров, сортировка по сумме/количеству, локальные изображения.
- Hover, keyboard focus, клик для закрепления, Escape для закрытия, подробная карточка с ценовой историей.
- Категориальная таблица со всеми категориями, расходами, количеством, уникальными заказами, скидкой и долей.
- Адаптивная верстка для desktop/mobile, раскрываемый блок «Как считаем».
- `window.dashboardTest` с состоянием, `setMonth`, `setCategory`, `reset`, `getTotals` для проверки.

## Важные решения

- Пустые месяцы в KPI-истории заполняются нулём; скидка для месяца без базы остаётся `null` и не соединяется линией.
- В истории цены товара месяцы без покупки остаются разрывами, а не нулевыми ценами.
- Подписи товаров не обрезаются CSS; при необходимости SVG сокращает длинную подпись только визуально с многоточием, полный текст доступен через detail-tooltip.
- Данные не вставляются через `innerHTML`: текст рендерится Vue или `d3.text`.


## Проверка и публикация

Проект создан в OpenCode на модели курса GPT-5.6 Sol; при проверке исправлены границы месяцев, шкалы и подсказки. Страница: https://artgas1.github.io/cu-visualization-hw4/ .

Контрольные значения: август 2026 — 8 доставленных заказов, 11 498 ₽, взвешенная скидка 1,03288%. Сентябрь 2024 — август 2026: 343 уникальных заказа и 533 109 ₽. Заказы неаддитивны по категориям.

Категории показывают полный состав трат за окно, выбранная категория выделена; фильтр меняет KPI, их динамику и товары. Месяц считается календарно, независимо от часового пояса браузера. Услуги участвуют в тратах и количестве заказов; физическое количество для услуг не выводится. Месяцы без покупки товара — пропуски в цене.

Данные учебные, вариант А. Опубликованы только поля, необходимые для анализа; адреса и время доставки исключены. Изображения — архив Items, приложенный преподавателем к семинару 4.
